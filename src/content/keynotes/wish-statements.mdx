<div>
  <h3>1. The Golden Rule</h3>
  <div class="bg-indigo-50 border border-indigo-100 rounded-md p-4 flex flex-col gap-2">
      <div class="handwriting font-bold text-xl flex items-center gap-2">
          <span>All Subjects</span>
          <span class="text-black font-sans text-sm">➜</span>
          <span class="highlighter-yellow">always use "WERE"</span>
      </div>
      <div class="handwriting text-lg text-gray-600 mt-1 border-t border-indigo-100 pt-2">
          Never use <span class="text-red-500 line-through">"was"</span>! <span class="text-sm text-gray-500 font-sans">(Even for I, He, She, It)</span>
      </div>
  </div>
</div>

<div>
  <h3>2. Tense Shifts</h3>
  <div class="handwriting text-gray-800 text-xl pl-4 border-l-4 border-indigo-200 flex flex-col gap-4">
      <div>
          <span class="font-sans font-bold text-gray-400 text-[10px] block uppercase tracking-wider mb-1">Unreal Now:</span>
          Fact: am / is / are <span class="text-gray-400 mx-2 text-sm font-sans">➜</span> <span class="highlighter-yellow font-bold text-indigo-700">were</span>

      <div>
          <span class="font-sans font-bold text-gray-400 text-[10px] block uppercase tracking-wider mb-1">Fact in Past:</span>

      </div>
  </div>
</div>
